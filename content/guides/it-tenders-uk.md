## Fit and eligibility checks before you bid

Read each opportunity's requirements before you commit time. These checks come up again and again in IT tenders:

1. **Cyber security certification.** Many public buyers ask for Cyber Essentials or Cyber Essentials Plus, and some ask for ISO 27001. Check what each tender requires early, because certification takes time.
2. **Data protection.** If you'll process personal data, expect questions on UK GDPR compliance, where data is hosted and who can access it.
3. **Accessibility.** Public sector websites and apps must meet accessibility rules, so web and software tenders often ask how you test against WCAG.
4. **Staff clearance.** Some contracts need staff with baseline or higher security clearance. Check before you bid if you'd need to clear new people.
5. **Insurance.** Buyers usually set minimum professional indemnity cover, and some ask for cyber insurance as well.
6. **Frameworks.** Some IT work is bought through frameworks rather than open tenders. Getting onto a framework can open the door to later call-off work, so treat it as a long-term investment.
7. **Social value.** Most public tenders now score social value alongside price and quality, so have specific, measurable commitments ready.

Under the [Procurement Act 2023](https://www.legislation.gov.uk/ukpga/2023/54/contents), which has applied to new procurements since 24 February 2025, buyers must publish how they'll assess bids, so read the award criteria before you write a word.
